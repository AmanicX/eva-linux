SYSTEM COMPONENTS & SCRIPTS

Eva Linux Architecture Catalog

Eva Linux delivers a modular, script-driven stack where each desktop component is independent, inspectable, and safely upgradeable.

eva-core (Installer & Setup Engine)

CORE ENGINE

The modular execution runner (install.sh and setup.sh) driving pre-flight validation, package installation via pacman and yay, dotfile symlinking, backup manifest logging, and automated recovery handlers.

niri-workstation (Infinite Scrollable Compositor)

WAYLAND

Niri scrollable tiling compositor configuration (~/.config/niri/config.kdl), tuned spring animation physics, column preset rules (33%, 50%, 66%), multi-monitor workspace boundaries, and trackpad gesture mappings.

noctalia-shell (Desktop Shell & Widgets)

SHELL

Noctalia 5 desktop shell integrating the top status capsule bar, quick settings flyout, PipeWire audio mixer, MPRIS media playback widget, and application launcher triggered by Super + Space.

quickshell-overlay (Interactive Keybind Cheatsheet)

OVERLAY

Interactive Wayland overlay triggered via Super + Shift + / that renders searchable hotkey categories, real-time conflict indicators, and physical key recording for fast customization.

terminal-dev (Kitty & LazyVim)

DEV TOOLS

GPU-accelerated Kitty terminal configured with Tokyo-Night palette, JetBrains Mono Nerd Font, Fastfetch system diagnostics, and LazyVim IDE pre-configured with Treesitter and LSP support.

eva-wallpaper-sync (Zero-Risk Bootloader Sync)

UTILITY

Safe synchronization utility that extracts Noctalia's active desktop wallpaper and seamlessly updates SilentSDDM and HyperFluent GRUB background images directly in place without dangerous grub-mkconfig rebuilds.

eva-restore (Automated Rollback Engine)

SAFETY

Instant rollback tool located in bin/eva-restore. Restores previous desktop configurations from timestamped tarball archives generated automatically prior to any installer execution.

Optional Themes (SilentSDDM, HyperFluent GRUB, Plymouth)

OPTIONAL

Modular styling packages for your login screen and boot sequence. Users choose whether to install or omit each component during the interactive setup process.
