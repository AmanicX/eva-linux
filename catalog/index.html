Component Catalog

A breakdown of the core modules, upstream software, configuration paths, and licenses comprising Eva Linux v2 Stable.

1. Niri Compositor

Scrollable tiling Wayland compositor with layout column presets, gesture support, and frosted glass background effects.

Config: ~/.config/niri/config.kdl • License: GPL-3.0-or-later

2. Noctalia 5 Desktop Shell

Wayland desktop shell providing the top capsule bar, workspace switcher, media player widget, unified control center, and dynamic theme palette generator.

State: ~/.local/state/noctalia/settings.toml • License: MIT

3. Quickshell Keybind Cheatsheet & Editor

Native Wayland overlay with search, physical keypress capture, live conflict resolution, and sandbox validation before modifying configuration.

Path: ~/.config/quickshell/keybinds/shell.qml • CLI: eva-keybinds-manager

4. SilentSDDM Greeter

Minimalist upstream SDDM greeter theme. Customized exclusively via background image replacement.

Path: /usr/share/sddm/themes/silent/ • License: GPL-3.0-only

5. HyperFluent GRUB Bootloader

Fluent bootloader theme updated automatically by wallpaper sync without requiring grub-mkconfig rebuilds.

Path: /boot/grub/themes/hyperfluent/ • License: MIT
