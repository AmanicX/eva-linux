Eva Linux v2.0.0 Stable

Latest Release
Released: November 2026
GitHub Release

Eva Linux v2.0.0 Stable marks a complete architectural transformation from legacy ISO build concepts to an elegant, idempotent, script-based setup installer. It reproduces the updated live desktop system configuration with pure upstream theming and zero-risk bootloader synchronization.

What's New in v2.0.0:

  • Modular Installer Architecture: Replaced monolithic 1,200-line shell scripts with 15 isolated, testable modules in modules/.
  • Quickshell Keybind Cheatsheet Overlay: Native Wayland overlay (Super + Shift + /) with instant search, physical keyboard key capture, live conflict resolution (Replace/Swap), and sandbox niri validate checking.
  • Pure Upstream Theming: Integrated upstream SilentSDDM v1.5.0 and HyperFluent GRUB preserving their original designs while enabling custom wallpaper backgrounds.
  • Zero-Risk Wallpaper Sync Engine: eva-wallpaper-sync synchronizes desktop wallpaper changes to SDDM and GRUB. GRUB background is updated directly in place without executing grub-mkconfig.
  • Configuration Backups & Recovery: Automated timestamped archives saved to ~/eva_backups/ with the interactive eva-restore CLI utility.
  • AUR Helper Compatibility: Eliminated hacky libalpm cross-version symlinks and --skippgpcheck flags; supports clean yay and paru installation.
  • Optional AI Chatbot Integration: Optional deployment for the Eva Advanced AI Chatbot studio.
